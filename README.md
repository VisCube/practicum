# Проектный Практикум

## О ветке

Основная функциональность ассистента на моделях [Cloud.ru](https://cloud.ru/docs) — LLM, STT.
Генеративный поиск с RAG и коннектор к Bitrix24 — в работе.

## Структура

```
.
├── src/
│   ├── main.py           # цикл диалога в консоли ввода
│   ├── assistant.py      # ассистент: обработка входящих сообщений + вызов инструментов
│   ├── config.py         # переменные окружения и системный промпт
│   ├── iam.py            # аутентификация в Cloud.ru по ключам
│   ├── transcribe.py     # распознавание речи через модель Speech-To-Text
│   └── tools/            # инструменты для function calling
│       ├── classifier.py # классификация обращений
│       ├── crm.py        # работа с CRM (временная заглушка)
│       └── search.py     # поиск по базе знаний (временная заглушка вместо RAG)
├── prompts/
│   └── assistant.md      # системный промпт ассистента
├── knowledge/            # база знаний: PDF-файлы с ответами на частые вопросы
└── classifier/           # обученная модель классификатора обращений
```
